# Documentation guide

Start with the [Stage 2 introduction](../README.md) for the story of the
experiment. The working guides below provide detail according to what you
want to understand or do.

## Working guides

| Guide | What it covers |
| --- | --- |
| [Methodology](methodology.md) | The objective, coverage and model-guided choices, validation, the taper and limitations |
| [Results and progress](../results/progress.md) | All eight functions' measured progress through round 2 and the pending Week 3 results |
| [Reproducing the analyses](reproducing-the-analyses.md) | Environment setup, historical data snapshots, report commands and provenance |
| [Notebook guide](../notebooks/README.md) | Individual analyses in the function/week folders |

The introductory diagrams and results chart can be rebuilt with the
[documentation figure script](../scripts/build_documentation_figures.py).
The diagrams use illustrative points; the chart uses the published result
records. The [reproduction guide](reproducing-the-analyses.md#documentation-figures)
describes the command and outputs.

## Final-deliverable templates

The [datasheet](datasheet.md), [model card](model-card.md) and
[non-technical summary](non-technical-summary.md) are unfinished templates.
Their bracketed prompts are not completed project findings. Replace these
prompts with evidence from the completed project before final submission.

The final repository will also need an account of the approach across all
eight functions, final progress plots and best observed inputs/outputs,
the rationale for Bayesian optimisation, challenges and practical insights,
and presentation links if required. The working guides provide the starting
material; they currently describe an ongoing experiment with two confirmed
rounds.
